# वीडियो प्लेयर (Android, Java)

- ऐप खुलते ही YouTube (m.youtube.com) खुलता है।
- किसी भी वीडियो / थंबनेल / Shorts पर क्लिक करो → लिंक अपने आप कॉपी होकर वीडियो प्लेयर में लोड होता है और चलने लगता है।
- YouTube / ब्राउज़र से "Share" करके इस ऐप को चुनो → वीडियो सीधे प्लेयर में चलेगा।
- कुछ वीडियो के मालिक बाहर चलाने की अनुमति नहीं देते; तब प्लेयर में "YouTube पर खोलें" दबाओ।

APK बनाना: GitHub पर अपलोड करो → Actions → Build APK → Artifacts से VideoPlayer-APK डाउनलोड करो।
